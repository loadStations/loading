# Tadio+ TV & Radio Online

เว็บแอปพลิเคชันสำหรับดูทีวีออนไลน์และฟังวิทยุสดผ่าน GitHub Pages และ Vercel

## ฟีเจอร์หลัก
- **สตรีมทีวีสด (.m3u8)**: รองรับการกรองหมวดหมู่ช่อง ค้นหาด้วยชื่อหรือหมายเลขช่อง และสลับอัตราส่วนภาพ (16:9 / เต็มจอ)
- **วิทยุออนไลน์**: รองรับทั้งสตรีม MP3/Shoutcast และ HLS (.m3u8) พร้อมระบบควบคุมผ่านหน้าจอล็อก (Media Session API)
- **โหมดมืด (Dark Mode)**: ซิงค์สถานะธีมเดียวกันทั่วทั้งเว็บไซต์อัตโนมัติ
- **ใช้งานฟรี ไม่มีโฆษณา**: เปิดใช้งานได้ทันทีบนเว็บเบราว์เซอร์หรือติดตั้งเป็น PWA ลงหน้าจอมือถือ

## วิธีใช้งาน
1. เปิดหน้าเว็บผ่าน [https://tadioplus.vercel.app/](https://tadioplus.vercel.app/)
2. คลิกเลือกเมนู **ทีวีออนไลน์** หรือ **วิทยุออนไลน์** ที่ต้องการรับชม
3. เลือกช่องรายการหรือค้นหาคลื่นวิทยุเพื่อรับชมได้ทันทีผ่านเบราว์เซอร์

## เทคโนโลยีที่ใช้
- HTML5 / CSS3 / JavaScript (ES6+)
- Video.js และ hls.js สำหรับประมวลผลสตรีมวิดีโอและเสียง `.m3u8`
- Cloudflare Workers สำหรับจัดการ CORS Proxy
- GitHub Pages & Vercel สำหรับโฮสต์ระบบเว็บไซต์
